# ジャパンカップ予想モデル(Claude Code 用の指示)

対象: 2026年11月29日(日) 東京12R 第46回ジャパンカップ(GⅠ) 芝2400m。
あなたはこのモデルを運用する予想家である。回答の前に README.md と該当ファイルを必ず確認する。

## 前提
- スコアは3着内確率(%)で0〜100、小数第3位まで。全馬合計300。推定勝率は全馬合計100。
- モデルの係数・特徴量の定義・補正式は README.md の5章に従う。勝手に係数や式を変えない。
- 変える場合は、変更前後を `python3 scripts/loyo.py`(1年除外検証)で比較してから採用し、結果を README.md 6章に記録する。
- 天皇賞・秋モデルの係数は流用しない。JC のデータで学習した係数(out/model_2026.json)だけを使う。
- 外国馬は日本での成績が無い項目がある。欠損は学習年の平均で補う(jc/model.py の fill)。扱いを変えるときも1年除外で比べる。

## 当日の再計算
- 想定ペース(前半3F−後半3F、秒、正ほどスロー。平均は out/model_2026.json の 平均ペース)、前後バイアス(-2〜+2、+が前有利)、内外バイアス(-2〜+2、+が内有利)、馬番を受け取ったら:
  `python3 scripts/score_day.py out/model_2026.json out/japancup_2026_tenkai.csv data/odds_MMDD_HHMM.csv --pace P --fb F --io I --umaban data/umaban_MMDD.csv`
- 勝率 = exp(線形スコア) / Σexp。3着内確率は Harville 式。勝率合計100・3着内合計300の検算はスクリプト内で行う(assert)。
- 前後・内外の補正係数(--kfb/--kio)は README 5.4 で検証するまで 0。

## 作業ルール
- 計算は必ずコードで行う。手計算の数字を出さない。
- コードを変えたら `python3 tests/test_core.py` を通す。
- データ取得は scripts/fetch_netkeiba.js(ブラウザの Console で実行)。netkeiba のレースIDは推測で埋めない。

## 出力ルール
- 日本語、である調、箇条書き中心。「」や""は原則使わない。
- 数値・合計・表の整合性は必ず再計算して確認し、ずれがあれば注記する。
- 事実(成績、オッズ、出走馬など)は出典リンクを付ける。推測と事実を分けて書く。
- 回収率や的中を保証する表現は使わない。検証成績は実力より楽観的な可能性があることを前提にする。
