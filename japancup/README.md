# ジャパンカップ 予想モデル(2026年版 第1版・Claude Code)

対象: 2026年11月29日(日) 東京12R 第46回ジャパンカップ(GⅠ) 芝2400m 3歳以上 定量。
出典: https://keibachannel.jp/?p=37896 (特別登録18頭、2026-11-23 時点)

このファイルは天皇賞・秋モデル(第13版)の構成を引き継いだ雛形である。係数・数値は未学習で、学習後に埋める。

## 1. 何をするモデルか
- 出走馬ごとに3着以内に入る確率(%)を出す。0〜100、小数第3位まで。全馬合計300。
- 推定勝率(%)も出す。全馬合計100。
- 学習データ: ジャパンカップ 1990〜2025年(取得できた範囲を記入)。取消・除外を除く。
- 単勝オッズを入力に使う。当日は出走30分前の単勝オッズ、想定ペース、前後バイアス、内外バイアス、馬番で再計算する。
- 印: 3着内スコア順に ◎1・○1・▲2・△2・☆2(計8頭)。
- 全頭メモ: 【点数】【強み】【弱み】【展開】【対戦】【印】(天皇賞・秋 memo_v11.py と同じ形式)。

## 2.2 パイプラインの検査結果(2026-11-23、天皇賞・秋データ 2006〜2025 で実行)
- 特徴_* 17列が、天皇賞・秋の学習データの値と全行一致(欠損の補い方: 着差なしの走は着順から 1着 −0.1・2着以下 0.15×(着順−1)、上限3.0。G1・G2なしは3.0、下限 −1.0。近3走の欠損着順は18、上限18。G1勝利数の上限5)。
- 人気だけの3着内対数損失 0.3381(天皇賞・秋 README 6.2 の 人気だけ 2006-25 0.3381 と一致)。
- このコードの1年除外(20年): 3着内対数損失 0.3337、印8頭の3着内 55/60、勝ち馬が印内 20年、◎の3着内 17年。天皇賞・秋 第11版(0.3268)より悪いのは、G1の距離・東京・海外別、乗替、前走脚余し、時代別補正を入れていないため。JC で入れるかは JC のデータで1年除外して決める。
- 当日式(5.3)のスコアと、モデル本体のスコアが全馬で一致(誤差1e-6以内)。
- Harville 式は全順列の総当たりと一致。

## 3. 天皇賞・秋モデルからの変更点(要検証)
- 距離適性の項目: 芝1800-2200成績 → 芝2200-2600成績。
- 外国馬: 列 外国馬(0/1)を追加。日本での成績が無い項目の補い方を決め、ここに記入する(候補: 外国馬だけの平均で補う/外国馬フラグを特徴量に入れる)。どちらも1年除外検証で比べてから採用する。
- 3歳馬: 斤量差があるため 特徴_3歳 の効き方を再確認する。
- 前走のローテーション(天皇賞・秋、凱旋門賞など海外G1、京都大賞典、アルゼンチン共和国杯)は傾向表を見て項目に入れない。入れる場合は結果を見る前に固定する。
- 発走が12Rのため、当日バイアスは1R〜11Rの芝で集計する。

## 4. データの取得元
- netkeiba.com データベース(レース結果、各馬の競走成績、出馬表)。race_id は netkeiba のレースページURLから確認して記入する。
- JRA 外国馬情報: https://www.jra.go.jp/news/202611/111306.html
- 2026-11-24 から作業環境(クラウド環境 Claude-)で db.netkeiba.com・race.netkeiba.com に接続できるようにし、scripts/fetch_netkeiba.py で直接取得した。
- race_id: 日付別レース一覧 https://db.netkeiba.com/race/list/YYYYMMDD/ の11月の日曜を調べ、レース名 ジャパンC(GI) のリンクから取った(data/race_ids.csv に出典URL)。2004年は同日のジャパンカップダートを除外。
- 2026年の出走予定馬: 出馬表 https://race.netkeiba.com/race/shutuba.html?race_id=202605050812(2026-11-24 取得、18頭、枠順は未確定)。
- 取得結果: 1990〜2025年 574頭(36回)+2026年 18頭 = 592行、取得エラー0。
### 4.1 取得スクリプトの検証(天皇賞・秋 2006・2015・2025、48頭)
- tests/tennosho_ref.csv と生の列を突き合わせ、一致しないのは 2006年の2件(ダンスインザムード 前々走_着差、アサクサデンエン 3走前_着差)だけ。下の海外着差の扱いを意図して変えたため。
- 特徴_* 18列は48頭すべてで一致。
- 天皇賞・秋の基準データから読み取った定義(展開の定義もこれで一致を確認):
  - 前走〜3走前: 直近3件の記録(取消・除外・中止を含む)のうち有効な走。間隔日数も取消・除外を含む直近の記録から数える。
  - 展開_*: 通過順のある国内の平地の走を新しい順に5走。初角率 =(最初のコーナー順位−1)/(頭数−1)、上がり差 = 上り − そのレースの後半3F、経験ペース差 = 前半3F − 後半3F。
### 4.2 取得時の補正(JC データで見つけたもの)
- 1990〜2001年は netkeiba のペース欄のカッコ内が 13.0-13.0 のように誤っている。本番ペースはラップの最初と最後の3本の合計から計算する(2025年は 34.5-34.6 でページ表示と一致)。
- 各馬の戦績のペースで20秒未満を含むもの(古いレース、地方の 0.0-36.2 など)、上りで20〜42秒の範囲外のもの(1990年前後の4F表記とみられる値、障害)は欠損扱い。障害レースは展開の集計から除く。
- 海外の走の 前走〜3走前_着差・上り・4角 は空欄にそろえる(netkeiba は年により値の有無がばらつく。天皇賞・秋の基準データでも海外54件中52件が空欄)。空欄は features.margin が着順から補う。
- 降着の着順 2(降) は数字として読む(以前は無効な走として通算から抜けていた。10行が修正された)。
- 父・父父・母父・展開_逃げ候補数・展開_先行馬数 は取得していない(特徴量に使っていない)。
- 2002年は中山芝2200mで開催された。学習データには含めている(除くかは未検証)。

## 5. モデル仕様(学習後に記入)
### 5.1 構造
- Plackett-Luce型の順位モデル。s = Σ(標準化特徴量 × 係数)。係数の向きを固定、オッズ以外は λ=300 で縮める(JC データの1年除外で選んだ。6章)。
- 学習: 1990〜2025年(36回、574頭)。
- 3着内確率は Harville 式で厳密計算。
### 5.2 特徴量
- jc/model.py の FEATS(24項目)。netkeiba に戦績が1走も無い外国馬79頭(1990〜2025年の外国馬186頭のうち)は、成績の項目を欠損にして学習年の平均で補う。前走海外=1・前走東京=0 は確定値として入れる(jc/features.py の foreign_unknown)。
- 係数(生の単位、train.py の出力): log市場確率 1.0888、東京芝3着内率 0.1009、枠 −0.0754、1番人気 −0.0464、初角率 −0.0459、上がり差 −0.0428、美浦所属 −0.037、6-9番人気 0.0343、2番人気 0.0323、10番人気以下 −0.0257、牝馬 0.025、外国馬 −0.019、前走海外 −0.0177、先行×ペース 0.0146、G1連対圏率 0.0138、通算勝率 0.0132、前走着差 −0.0128、前走東京 0.0127、3歳 −0.0097、近3走G1G2最小着差 −0.008、近3走平均着順 −0.007、6歳以上 −0.0069、上がり×ペース 0.0023、前走人気 −0.0019(前走G1・G1勝利数・G1出走なし は 0)。
- 市場確率以外の項目の寄与は小さく、スコアはほぼ単勝オッズの順になる。
### 5.3 当日の計算式
線形スコア = 基礎値a + ペース感応度b ×(想定ペース − JC平均ペース)
          + c × ln(市場確率) + 人気帯の補正 + 枠の補正
          + k1 × 前後バイアス/2 ×(0.5 − 初角率)/0.5
          + k2 × 内外バイアス/2 ×(0.5 − 馬番位置)/0.5
- JC平均ペース = 0.906秒(1990〜2025年、ラップから計算した前半3F−後半3F の平均)
- c = 1.0888、1番人気 −0.0464、2番人気 0.0323、6-9番人気 0.0343、10番人気以下 −0.0257、枠 −0.0754(16頭以上のとき)、k1 = k2 = 0(5.4 で検証するまで)
- 勝率 = exp(線形スコア) / Σexp。3着内確率は Harville 式。
- 取消・除外は単勝オッズを空欄にし、市場確率・人気・頭数を残りの馬で計算し直す。

### 6.1 1年除外検証(1990〜2025年、36年、2026-11-24)

- 3着内の総数109 = 36年×3 + 1996年の3着同着1頭。印8頭の3着内は同着を含めて数えている。
- 採用: λ=300・欠損扱い。モデルの中で PL負対数尤度が最小で、3着内対数損失も最小(λ=1000 の 0.3348)と差が無い。
- 結論: どの設定でも PL負対数尤度は人気だけを下回らず、3着内対数損失の差も最大 0.0003(λ=1000)。**JC では、特徴量は単勝オッズにほとんど情報を足していない**。λ を同じ検証で選んでいるため、この成績自体もやや楽観的である。
- 天皇賞・秋 README から引き継いだ G1の距離・東京・海外別、乗替、前走脚余し、時代別補正 は入れていない。
- 1年除外検証: 対数損失、PL負対数尤度、印8頭の3着内、勝ち馬が印内の年数。人気だけの予想と比較する。
- 注意: 項目選びに結果を見ている場合、検証成績は実力より楽観的になる。

## 8. 運用手順
1. 枠順確定後(11/26予定、JRA発表で確認): 出走馬・馬番・騎手を確認し umaban_MMDD.csv を作る。
2. 展開予想を出す。
3. 当日 出走30分前: 単勝オッズ・想定ペース・前後/内外バイアス・馬番を入れて再計算。中立スコアと展開スコアの両方を確認。
4. データのみ・混合の2種類で印とメモを確認。
5. レース後: result_2026.csv に全着順・確定オッズ・ラップを入れ、版ごとの比較を記録する。
