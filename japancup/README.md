# ジャパンカップ 予想モデル(2026年版 第1版・Claude Code)

対象: 2026年11月29日(日) 東京12R 第46回ジャパンカップ(GⅠ) 芝2400m 3歳以上 定量。
出典: https://keibachannel.jp/?p=37896 (特別登録18頭、2026-11-23 時点)

このファイルは天皇賞・秋モデル(第13版)の構成を引き継いだ雛形である。係数・数値は未学習で、学習後に埋める。

## 1. 何をするモデルか
- 出走馬ごとに3着以内に入る確率(%)を出す。0〜100、小数第3位まで。全馬合計300。
- 推定勝率(%)も出す。全馬合計100。
- 学習データ: ジャパンカップ 1990〜2025年(取得できた範囲を記入)。取消・除外を除く。
- 単勝オッズを入力に使う。当日は出走30分前の単勝オッズ、想定ペース、前後バイアス、内外バイアス、馬番で再計算する。
- 印: 3着内スコア順に ◎1・○1・▲2・△2・☆2(計8頭)。
- 全頭メモ: 【点数】【強み】【弱み】【展開】【対戦】【印】(天皇賞・秋 memo_v11.py と同じ形式)。

- tests/tennosho_ref.csv と生の列を突き合わせ、一致しないのは 2006年の2件(ダンスインザムード 前々走_着差、アサクサデンエン 3走前_着差)だけ。下の海外着差の扱いを意図して変えたため。

### 4.2 取得時の補正(JC データで見つけたもの)
- 1990〜2001年は netkeiba のペース欄のカッコ内が 13.0-13.0 のように誤っている。本番ペースはラップの最初と最後の3本の合計から計算する(2025年は 34.5-34.6 でページ表示と一致)。
- 各馬の戦績のペースで20秒未満を含むもの(古いレース、地方の 0.0-36.2 など)、上りで20〜42秒の範囲外のもの(1990年前後の4F表記とみられる値、障害)は欠損扱い。障害レースは展開の集計から除く。
- 海外の走の 前走〜3走前_着差・上り・4角 は空欄にそろえる(netkeiba は年により値の有無がばらつく。天皇賞・秋の基準データでも海外54件中52件が空欄)。空欄は features.margin が着順から補う。
- 降着の着順 2(降) は数字として読む(以前は無効な走として通算から抜けていた。10行が修正された)。
- 父・父父・母父・展開_逃げ候補数・展開_先行馬数 は取得していない(特徴量に使っていない)。
- 2002年は中山芝2200mで開催された。学習データには含めている(除くかは未検証)。

## 5. モデル仕様(2026-11-24 最適化後)
### 5.1 構造
- Plackett-Luce型の順位モデル。s = Σ(標準化特徴量 × 係数)。基本項目の係数の向きは固定、当日バイアス2項は自由、オッズ以外は λ=30 で縮める。
- 学習: 2006〜2025年(20回)。学習開始年(1990/2000/2006)・λ(10/30/100)・符号制約(固定/自由)・特徴量ブロックを JC データで最適化して選んだ(6.3)。
- 3着内確率は Harville 式で厳密計算。
### 5.2 特徴量
- jc/model.py の FEATS(24項目)+ BIAS(バイアス前後・バイアス内外)の26項目。JC追加候補(乗替・G1中長距離3着内率・東京G1_3着内率・海外G1_3着内率・前走脚余し・間隔日数log・前走天皇賞秋)と 時代×市場 は検証で効かず不採用(6.3)。netkeiba に戦績が1走も無い外国馬は、成績の項目を欠損にして学習年の平均で補う(1990〜2025年で186頭中79頭、2006〜2025年で62頭中1頭)。前走海外=1・前走東京=0 は確定値として入れる(jc/features.py の foreign_unknown)。
- 係数(生の単位、train.py の出力): log市場確率 1.073、バイアス前後 0.6076、東京芝3着内率 0.4529、2番人気 −0.4293、枠 −0.3089、バイアス内外 0.2658、上がり差 −0.2299、美浦所属 −0.1771、外国馬 −0.1739、前走東京 0.1477、3歳 −0.1354、初角率 0.1044、前走海外 −0.1027、6歳以上 −0.0963、牝馬 0.0963、6-9番人気 0.0709、通算勝率 0.0695、前走G1 0.066、10番人気以下 −0.0594、上がり×ペース 0.0328、近3走G1G2最小着差 −0.0327、近3走平均着順 −0.028、先行×ペース −0.0267、1番人気 0.0175、前走着差 −0.0062、前走人気 −0.0039(G1勝利数・G1連対圏率・G1出走なし は 0)。
- 主な効き方: 東京芝の3着内率が高い馬・前走東京の馬を加点、2番人気・外枠・上がりの遅い馬・外国馬・美浦所属・3歳・6歳以上を減点。当日が前残りなら先行馬、内有利なら内枠を加点。
### 5.3 当日の計算式
線形スコア = 基礎値a + ペース感応度b ×(想定ペース − JC平均ペース)
          + c × ln(市場確率) + 人気帯の補正 + 枠の補正
          + k1 × 前後バイアス/2 ×(0.5 − 初角率)/0.5
          + k2 × 内外バイアス/2 ×(0.5 − 馬番位置)/0.5
- JC平均ペース = 1.195秒(2006〜2025年、ラップから計算した前半3F−後半3F の平均)
- c = 1.073、1番人気 0.0175、2番人気 −0.4293、6-9番人気 0.0709、10番人気以下 −0.0594、枠 −0.3089(16頭以上のとき)、k1 = 0.6076、k2 = 0.2658(5.4)
- 初角率は過去5走の値(欠損は 0.5 = 補正なし)。馬番位置 =(馬番−1)/(頭数−1)。
- 勝率 = exp(線形スコア) / Σexp。3着内確率は Harville 式。
- 取消・除外は単勝オッズを空欄にし、市場確率・人気・頭数を残りの馬で計算し直す。
### 5.4 当日補正の係数
- 前残り度・内外度の定義(scripts/fetch_bias.py): JC 当日、同じ開催で JC より前の芝の平地レースの1〜3着馬について 4角率 =(最後のコーナー順位−1)/(頭数−1)、馬番率 =(馬番−1)/(頭数−1)の平均を取り、1990〜2025年の平均・標準偏差(4角率 0.3465±0.0670、馬番率 0.4827±0.0694)で標準化して符号を反転、−2〜+2 に切る。+ほど前有利・内有利。
- k1(前後)= 0.6076、k2(内外)= 0.2658。学習データの各年の実際の値を特徴量に入れて PL で同時に推定した(符号は自由、どちらも正で想定どおりの向き)。
- 1年除外(2006〜2025年): バイアス項なし PL 105.665 / 3着内LL 0.2878 → あり PL 104.764 / 0.2825。
- 参考: 当日の前残り度と本番3着内の4角率の相関 −0.035、内外度と本番3着内の馬番率の相関 −0.212(36年)。単独では弱く、他の項目と組み合わせて効いている。
- 当日の計算: scripts/day_bias.py(race.netkeiba.com の速報結果)。2025年で検証すると 前残り度 −0.434(保存値と一致)、内外度 −0.976(保存値 −0.978。保存値の当日馬番率を小数第3位に丸めたため標準偏差がわずかに違う)。

### 6.3 JC データでの最適化(2026-11-24、scripts/optimize.py)
- 基準: 1年除外の PL負対数尤度。選択の楽観度を見るため、2006〜2020年だけで選び、2021〜2025年(選択に使っていない)で確認した。
- 特徴量を1つずつ選ぶ方法(後退・前進選択、--mode greedy)は過学習した: 2006〜2020年では PL 81.132(人気だけ 85.264)だったが、2021〜2025年は 23.029 で人気だけ(22.022)より悪い。不採用。
- ブロック単位の選択(--mode block): 基本(FEATS)は常に入れ、JC追加候補・時代×市場・当日バイアスの有無 × 学習開始年 × λ × 符号制約 の総当たり(8×3×3×2=144通り)。

|---|---|---|---|
| 人気だけ | 22.022 | 0.2366 | – |
| 秋天と同じ初期設定(基本、2006〜、λ=30) | 20.935 | 0.2329 | 14/15 |
