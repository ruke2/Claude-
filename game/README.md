# ジョッキー・ライフ（ドラフト版）

1人の騎手として、2027年3月のデビューから引退までを1鞍ずつ進めるスマホ横画面向けのブラウザゲーム。

## 遊び方

`game/index.html` をブラウザで開く（ローカルで試す場合は `python3 -m http.server` で `game/` を配信する）。

- **週の画面**: 騎乗依頼を受ける（1レース1頭まで）。平日の過ごし方を選ぶ。海外遠征の依頼が来ることもある
- **開催日**: 1日12レース。騎乗するレースはパドックからジョッキーカメラで騎乗するか、オートで騎乗する。乗らないレースは見送る
- **レース操作**: ◀▶で進路変更、控える（脚をためる）、追う（加速）、ムチ（12回まで）。前に馬がいると壁になり、コーナーでは外を回るほど距離をロスする。折り合いを欠くとスタミナを余分に使う

## データについて

- 実在馬: `js/realhorses.js`。JRA公式の2026年GⅠ成績ページ（13レース）に出走した馬の、馬名、性別、生年（2026年時点の競走年齢から算出）、着順。各馬の `src` に出典URLを記載
  - 能力値・脚質・得意距離は、着順と通過順から本ゲーム用に算出した推定値
- GⅠの日程・条件: JRA「2026年 GⅠレース一覧」に準拠し、翌年以降も同じ「第n日曜」に開催する扱い
- GⅡ・GⅢの時期、海外レースの時期と条件、コース形状、見習騎手の減量ルールは、ゲーム用の概略・簡略化
- 騎手・調教師・架空馬はすべて架空

非公式のファンメイド作品。実在の騎手は登場しない。
