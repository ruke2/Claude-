# ジョッキー・ライフ（ドラフト版 v2）

1人の騎手として、2027年3月のデビューから引退までを1鞍ずつ進めるスマホ横画面向けのブラウザゲーム。

## 遊び方

`game/index.html` をブラウザで開く。ローカルで試すときは `game/` で `python3 -m http.server` を実行する（テクスチャを読み込むため、ファイルを直接開くのではなくサーバー経由で開く）。

### レース（3D・ジョッキーカメラ）
- **進路（左下）**: 左右にスライドして内・外へ。横に馬がいるのに寄せると接触・斜行になり、審議（降着・騎乗停止）の対象になる
- **手綱（右端）**: 上で行かせる、下で抑える。位置は保持される。抑えすぎると気の強い馬はかかる（馬の後ろに入れると落ち着く）
- **押す**: 黄色い輪がボタンの縁に重なる瞬間（完歩の頭）に押すと伸びる。ずれるとリズムが崩れる
- **ムチ（左・右）**: 伸びを上乗せ。馬はムチと反対側へ寄るので、疲れてヨレた馬の修正にも使う
- **視点**: 騎手／後方／中継 を切り替えられる

### レース以外
- **今週**: 騎乗依頼（斤量と体重の兼ね合い、馬主・調教師、お手馬、主戦）、平日の予定3枠、海外遠征の依頼
- **出来事**: 取材依頼、食事の誘い、エージェントの売り込み、主戦騎手の打診、CM出演、ライバルの挑発など
- **勝利騎手インタビュー**: 回答で評価・人気・関係者の信頼が変わる
- **人脈**: 馬主（架空10）、調教師、エージェント、ライバル3人との対戦成績
- **騎手**: 能力、体重・体調・疲労、所持金、ファン数、人気順位
- **ニュース・キャリア・年間表彰**

## 技術とデータ

- 描画: Three.js r147（jsDelivr）
- 芝・砂・空のテクスチャ: [Poly Haven](https://polyhaven.com/)（CC0）の leafy_grass, grass_ground, park_sand, damp_sand, kloofendal_48d_partly_cloudy_puresky を縮小・色調補正して `assets/` に収録
- 馬のモデル: [“Horse” by Henry S](https://sketchfab.com/3d-models/horse-a6f860e43e364619bccb174a1ac7d0c9)（Sketchfab, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）。FBX を glb に変換し、ギャロップ・待機・常歩のアニメーションだけを残した。白斑を除いて毛色を塗り替えられるテクスチャに加工し、ウエスタン鞍は外してレース用の鞍とゼッケンに差し替えている（`assets/horse.glb` ほか）
- 騎手のモデル: 手続き生成（`js/horse3d.js`）
- 効果音: WebAudio で合成（音源ファイルなし）
- 実在馬: `js/realhorses.js`。JRA公式の2026年GⅠ成績ページ（13レース）に出走した馬の、馬名・性別・生年・着順。各馬の `src` に出典URL
  - 能力値・脚質・得意距離は着順と通過順から算出した本ゲーム用の推定値
- GⅠの日程・条件は JRA「2026年 GⅠレース一覧」に準拠。GⅡ・GⅢの時期、海外レース、コース形状、見習騎手の減量、賞金の取り分などはゲーム用の概略
- 騎手・調教師・馬主・エージェント・架空馬はすべて架空
