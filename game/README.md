# ジョッキー・ライフ（ドラフト版 v2）

1人の騎手として、2027年3月のデビューから引退までを1鞍ずつ進めるスマホ横画面向けのブラウザゲーム。

## 遊び方

ブラウザ版（GitHub Pages）: https://ruke2.github.io/Claude-/game/ （リポジトリの Settings → Pages で公開を有効にした後）

`game/index.html` をブラウザで開く。ローカルで試すときは `game/` で `python3 -m http.server` を実行する（テクスチャを読み込むため、ファイルを直接開くのではなくサーバー経由で開く）。

### レース（3D・ジョッキーカメラ）
- **◀ ▶（左下）**: 押している間、内・外へ進路を変える。横に馬がいるのに寄せると接触・斜行になり、審議（降着・騎乗停止）の対象になる
- **手綱（右）**: 行かせる／ふつう／抑える の3段階。抑えすぎると気の強い馬はかかる（馬の後ろに入れると落ち着く）
- **追う（長押し）**: 押している間、騎手が追い続けて加速する
- **ムチ**: 伸びを上乗せ。打つ側は馬のヨレを戻す向きに自動で選ぶ
- **コーチ（画面上）**: 今から全力で追って持つ距離をバーで表示。残り距離に届いたら仕掛けどき

### ストーリー
師匠・同期のライバル・自分で名付ける相棒の馬との物語。第1章 見習い → 第2章 一人前へ → 第3章 相棒 → 第4章 クラシック（日本ダービー）→ 第5章 世界へ（凱旋門賞）→ 第6章 伝説へ。
- **視点**: 騎手／後方／中継 を切り替えられる

### 騎手としての成長・人気・生活
- **レベルとスキル**: 騎乗で経験値、レベルアップでスキルポイント。スタート名人・折り合い名人・ムチさばき・イン突き・追い込みの鬼など12種類
- **称号・実績・トロフィー**: 見習い〜レジェンドの称号、24の実績、GⅠのトロフィー棚
- **人気**: ファン層（競馬ファン・若い世代・女性・地元）、SNSフォロワー、応援メッセージ、年末の騎手人気投票
- **ショップ**: 装備（鞍・ムチ・ブーツ・ゴーグル）、スタッフ（トレーナー・栄養士・マネージャー）、住まい
- **シーズン目標**: 毎年はじめに3つから選び、年末に達成度で報酬
- **私生活**: 家族・友人・出会いから結婚まで
- **画面の向き**: 縦向き（向きロック中）でも、画面ごと横向きに回して表示する

### レース以外
- **今週**: 騎乗依頼（斤量と体重の兼ね合い、馬主・調教師、お手馬、主戦）、平日の予定3枠、海外遠征の依頼
- **出来事**: 取材依頼、食事の誘い、エージェントの売り込み、主戦騎手の打診、CM出演、ライバルの挑発など
- **勝利騎手インタビュー**: 回答で評価・人気・関係者の信頼が変わる
- **人脈**: 馬主（架空10）、調教師、エージェント、ライバル3人との対戦成績
- **騎手**: 能力、体重・体調・疲労、所持金、ファン数、人気順位
- **ニュース・キャリア・年間表彰**

## 技術とデータ

- 描画: Three.js r147（jsDelivr）
- BGM: "Green Hills" by Igor Gundarev（CC0）https://opengameart.org/content/green-hills をモノラル化して `js/audio-data.js` に収録
- 歓声: "Arrowhead Stadium crowd noise" by Kj1595（CC BY-SA 4.0）https://commons.wikimedia.org/wiki/File:Arrowhead_Stadium_crowd_noise.wav を切り出し・モノラル化して `js/audio-data.js` に収録。この音源部分は CC BY-SA 4.0 で提供する
- ファンファーレ: "Call to the Post (First Call)" U.S. Army Bands Online（米国政府の著作物・パブリックドメイン）https://archive.org/details/CallToThePostFirstCall を `js/audio-data.js` に収録
- 芝・砂・空のテクスチャ: [Poly Haven](https://polyhaven.com/)（CC0）の leafy_grass, grass_ground, park_sand, damp_sand, kloofendal_48d_partly_cloudy_puresky を縮小・色調補正して `assets/` に収録
- 馬のモデル: [“Horse” by Henry S](https://sketchfab.com/3d-models/horse-a6f860e43e364619bccb174a1ac7d0c9)（Sketchfab, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）。FBX を glb に変換し、ギャロップ・待機・常歩のアニメーションだけを残した。白斑を除いて毛色を塗り替えられるテクスチャに加工し、ウエスタン鞍は外してレース用の鞍とゼッケンに差し替えている（`assets/horse.glb` ほか）
- 騎手のモデル: 手続き生成（`js/horse3d.js`）
- 効果音: WebAudio で合成（音源ファイルなし）
- 実在の騎手: `js/realjockeys.js`。JRA公式「2026年度 リーディングジョッキー（全国）」（2026年11月15日現在）の上位39人の名前・所属・生年・初免許年・2026年の成績。ゲーム内の腕前はその勝率と勝利数から換算したもので、ゲーム内の成績・出来事はすべて架空。物語に出てくる同期・兄弟子は架空の騎手
- 実在馬: `js/realhorses.js`。JRA公式の2026年GⅠ成績ページ（13レース）に出走した馬の、馬名・性別・生年・着順。各馬の `src` に出典URL
  - 能力値・脚質・得意距離は着順と通過順から算出した本ゲーム用の推定値
- GⅠの日程・条件は JRA「2026年 GⅠレース一覧」に準拠。GⅡ・GⅢの時期、海外レース、コース形状、見習騎手の減量、賞金の取り分などはゲーム用の概略
- 騎手・調教師・馬主・エージェント・架空馬はすべて架空

## セーブ
- 端末のブラウザに保存する（保存先の名前は固定。更新しても消えない）。上書きのたびに直前のセーブを控えとして残す
- 古い版のセーブは読み込み時に新しい項目を補う（`World.migrate`）
- claude.ai の Artifact として開いたときは、自分だけが読み書きできる場所にも圧縮して自動保存する（`js/cloudsave.js`）。端末の保存領域が消えても、タイトル画面の「クラウドのセーブから再開」で戻せる
- タイトル画面とメニューから、セーブをファイルに書き出す・読み込むことができる
