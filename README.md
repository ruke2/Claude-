# SOGO SHOSHA 〜総合商社経営〜

ターン制の総合商社経営シミュレーション。街の小さな貿易商から、世界最大の総合商社を目指す。
ビルド不要の静的サイト（HTML / CSS / Vanilla JS）。`index.html` をブラウザで開けば遊べる。

## 遊び方

時間軸は3層になっている。

| 層 | 周期 | やること |
|---|---|---|
| オペレーション | 毎月 | 商談・応札・資金繰り |
| 経営 | 年1回（3月） | 決算・格付レビュー・資源配分・株主還元 |
| 戦略 | 3年に1回 | 中期経営計画の策定とコミット |
| 昇格 | 純資産が目標に到達 | 扱える案件の桁が変わる |

1. **商談** — 持ち込まれた案件に応札する。提示条件（捨値〜暴利）で落札確度と利幅がトレードオフになる。
2. **翌月へ** — 月を進めると市況が動き、進行中案件の損益が確定する。
3. **本社** — 稼いだ資金を営業本部・人員・海外拠点・財務に再投資する。
4. **決算（3月）** — 4ステップのウィザードで1年の経営を決める。

### 決算ウィザード（年1回）

1. **決算発表** — セグメント別損益。どの本部が会社を食わせているかが見える
2. **格付レビュー** — 信用力・ROE・D/E・サステナ投資から格付が決まる。借入枠と調達金利に直結
3. **資源配分** — 翌1年の投資予算を6本部＋コーポレート3枠に配る。**配らなかった本部は地力を失い、やがてレベルが下がる**
4. **株主還元** — 配当性向と自社株買いを決める。株主信任と PBR が動く

資源配分は集中投下が有利（検証AIで集中135ヶ月 < 分散146 < 無投資150）。ただし張った分野の市況が逆回転すると丸ごと沈む。

### 中期経営計画（3年に1回）

決算ウィザードに2ステップが挿し込まれる。

**策定** — 3年分の約束を自分で決める。

- 数値目標3つ（最終年度 純利益 / 最終年度 ROE / 3年累計 投資額）を保守的・標準・挑戦的から選ぶ
- 重点戦略カードを8枚から2枚選ぶ。効果は3年間continuous

**総括** — 3年後に評価される。

| 達成 | 起きること |
|---|---|
| 3/3 | 株主信任・格付・PBR が上昇。**実績ボーナス**が積み上がり投資余力と落札力が恒久的に増す |
| 2/3 | 中立 |
| 1/3 | 信任が下がる |
| 0/3 | 信任・格付が急落、PBR −22%、実績ボーナスを失う |

挑戦的な目標ほど達成時の実績ボーナスが大きい（検証AIでの全項目達成率: 保守的95% / 標準74% / 挑戦的45%）。

#### 重点戦略カード

| カード | 効果 | 代償 |
|---|---|---|
| 資源メジャー化 | 権益案件の出現率2.6倍・利回り+26% | 減損リスク+32% |
| 非資源シフト | トレード・事業投資が増え採算+5% | 権益がほぼ出ない |
| アジア・パシフィック深耕 | 該当3地域の案件が1.35倍・落札力+9pt・拠点費35%減 | 他地域の落札力−4pt |
| 脱炭素トランジション | 生活産業・機械の案件増、減損−20%、サステナ水準が毎年+0.45 | 化石燃料権益の利回り−15% |
| デジタル戦略 | 商談枠+1、販管費−10%、DX水準が毎年+0.34 | 直接の売上を生まない |
| 人材投資 | 同時進行できる案件+4、人材水準が毎年+0.45 | 人件費+10% |
| 財務規律 | 調達金利−0.7%、信用が積み上がる | 借入枠−15% |
| グローバル・パートナーシップ | 大型案件が出やすく全案件+15% | 競合が1社増える |

検証AIでのカード組み合わせ別クリア月数: 非資源+DX 138 / アジア+人材 129 / 財務規律+脱炭素 139 / 資源+提携 154。

勝ち筋は、トレードで稼いだフローを **権益・事業投資というストック収益** に変えていくこと。
無謀にレバレッジを効かせると格付が落ち、借入枠が縮み、資金繰りで死ぬ。

## 案件の4類型

| 種別 | 性格 |
|---|---|
| トレード | 運転資金を拠出し口銭を抜く短期取引。市況と為替で採算が振れる |
| プロジェクト | EPC/インフラ。毎月工事原価が出て竣工時に一括回収。遅延で原価が膨らむ |
| 資源権益 | 巨額の初期投資と引き換えに長期配当。市況低迷が続くと減損 |
| 事業投資 | 事業会社への出資。安定配当が毎月入り、投資先が自律的に成長する |

## シミュレーション要素

- 商品市況6種（原油・LNG・鉄鉱石・銅・穀物・海上運賃）の対数平均回帰ランダムウォーク
- USD/JPY と政策金利の変動
- 地政学・気象・規制・信用不安など20種のイベント
- 信用力・ROE・D/E・サステナ投資 → 格付（AAA〜CCC）→ 借入枠・調達金利・落札力に波及
- 株価・時価総額・PBR・ROE・株主信任。PBR 1倍割れは資本効率の警告
- 昇格時、PBR が1倍を超えていれば公募増資で資金を調達できる
- D/E が 1.0 を超えると格付が毀損する財務規律
- 与信デフォルト、工程遅延、減損損失、資金繰り破綻（4ヶ月連続の債務超過でゲームオーバー）
- ライバル商社10社との世界ランキング

## 構成

```
index.html          エントリ
css/style.css       スタイル（ダーク／モバイルファースト）
js/data.js          静的データ（本部・案件テンプレ・イベント・ステージ）
js/engine.js        ゲームエンジン（会計・市況・入札・ターン処理・セーブ）
js/ui.js            描画レイヤー
js/main.js          入力配線
tools/              検証・ビルド用（ゲーム本体からは参照しない）
```

会計は **純資産 ＝ 現金 ＋ 簿価資産 － 有利子負債** で一貫しており、
損益計算書の各項目は必ず現金または簿価の増減と対になっている
（本部投資・採用・拠点開設・株主還元は資本取引として損益から分離）。

進行状況は `localStorage` に自動保存される。

## 開発用コマンド

```bash
node tools/sim.js 300 24     # 慎重な経営者AIでのバランス検証（昇格までの月数など）
SPREAD=1 node tools/sim.js    # 分散投資での対照実験
CARDS=resource node tools/sim.js  # 戦略カード別の検証（balanced/resource/asia/safe）
TIER=2 node tools/sim.js      # 中計の目標難易度別の検証（0/1/2）
NOBUDGET=1 node tools/sim.js  # 予算配分なしでの対照実験
node tools/reckless.js 40    # 無謀な経営での破綻率
node tools/diag.js 30        # 月次の損益内訳トレース
node tools/build.js          # dist/index.html に単一ファイルとして出力
node tools/playtest.js       # 実ブラウザでのスモークテスト（要 playwright）
```
