# SOGO SHOSHA 〜総合商社経営〜

ターン制の総合商社経営シミュレーション。街の小さな貿易商から、世界最大の総合商社を目指す。
ビルド不要の静的サイト（HTML / CSS / Vanilla JS）。`index.html` をブラウザで開けば遊べる。

## 遊び方

時間軸は3層になっている。

| 層 | 周期 | やること |
|---|---|---|
| オペレーション | 毎月 | 商談・応札・資金繰り |
| 経営 | 年1回（3月） | 決算・格付レビュー・資源配分・株主還元 |
| 戦略 | 3年に1回 | 中期経営計画の策定とコミット |
| 信任 | 6年に1回 | 社長信任投票（不信任＝ゲームオーバー） |
| 昇格 | 純資産が目標に到達 | 扱える案件の桁が変わる |

1. **商談** — 持ち込まれた案件に応札する。提示条件（捨値〜暴利）で落札確度と利幅がトレードオフになる。
2. **翌月へ** — 月を進めると市況が動き、進行中案件の損益が確定する。
3. **本社** — 稼いだ資金を営業本部・人員・海外拠点・財務に再投資する。
4. **決算（3月）** — 4ステップのウィザードで1年の経営を決める。

### 決算ウィザード（年1回）

1. **決算発表** — セグメント別損益。どの本部が会社を食わせているかが見える
2. **格付レビュー** — 信用力・ROE・D/E・サステナ投資から格付が決まる。借入枠と調達金利に直結
3. **資源配分** — 翌1年の投資予算を6本部＋コーポレート3枠に配る。**配らなかった本部は地力を失い、やがてレベルが下がる**
4. **株主還元** — 配当性向と自社株買いを決める。株主信任と PBR が動く

資源配分は集中投下が有利（検証AIで集中135ヶ月 < 分散146 < 無投資150）。ただし張った分野の市況が逆回転すると丸ごと沈む。

### 中期経営計画（3年に1回）

決算ウィザードに2ステップが挿し込まれる。

**策定** — 3年分の約束を自分で決める。

- 数値目標3つ（最終年度 純利益 / 最終年度 ROE / 3年累計 投資額）を保守的・標準・挑戦的から選ぶ
- 重点戦略カードを8枚から2枚選ぶ。効果は3年間continuous

**総括** — 3年後に評価される。

| 達成 | 起きること |
|---|---|
| 3/3 | 株主信任・格付・PBR が上昇。**実績ボーナス**が積み上がり投資余力と落札力が恒久的に増す |
| 2/3 | 中立 |
| 1/3 | 信任が下がる |
| 0/3 | 信任・格付が急落、PBR −22%、実績ボーナスを失う |

挑戦的な目標ほど達成時の実績ボーナスが大きい（検証AIでの全項目達成率: 保守的95% / 標準74% / 挑戦的45%）。

#### 重点戦略カード

| カード | 効果 | 代償 |
|---|---|---|
| 資源メジャー化 | 権益案件の出現率2.6倍・利回り+26% | 減損リスク+32% |
| 非資源シフト | トレード・事業投資が増え採算+5% | 権益がほぼ出ない |
| アジア・パシフィック深耕 | 該当3地域の案件が1.35倍・落札力+9pt・拠点費35%減 | 他地域の落札力−4pt |
| 脱炭素トランジション | 生活産業・機械の案件増、減損−20%、サステナ水準が毎年+0.45 | 化石燃料権益の利回り−15% |
| デジタル戦略 | 商談枠+1、販管費−10%、DX水準が毎年+0.34 | 直接の売上を生まない |
| 人材投資 | 同時進行できる案件+4、人材水準が毎年+0.45 | 人件費+10% |
| 財務規律 | 調達金利−0.7%、信用が積み上がる | 借入枠−15% |
| グローバル・パートナーシップ | 大型案件が出やすく全案件+15% | 競合が1社増える |

### 人材（幹部社員）

社員数（量）とは別に、**幹部社員**を個別の人物として最大24名まで抱える。

- **能力3種** — 営業力（落札力と実現利益）／目利き（減損の抑制）／統率（同時処理数・本部の成長）
- **特性** — 中東の顔役、ミスター・エネルギー、目利き、タフネゴシエーター、財務のプロ、人たらし ほか16種
- **性格** — 熱血・冷静・皮肉屋・温厚。入社／昇進／退社／大型案件の応札で発言が変わる
- **配属と駐在** — 本部に配属し、本部長に任命する。海外拠点に駐在させると成長が35%速くなりその地域の落札力 +6pt
- **士気** — 業績・株主信任・人材投資で動く。低いと引き抜かれ、落札力も落ちる

幹部が誰もいない本部は落札力 −9pt、実現利益 ×0.91 になる。商談枠も幹部の役職の重みで決まるので、**人を採らないと商談の回転数そのものが落ちる**。

#### 給与体系

年収はすべて **階級 × 給与水準 × 会社規模 × 本人の能力** で決まり、万円単位で表示される。

| 階級 | 基準年収（創業規模・標準水準） |
|---|---|
| 担当 | 1,050万 |
| 課長 | 1,650万 |
| 部長 | 2,400万 |
| 本部長 | 3,600万 |
| 役員 | 6,000万 |
| 一般社員（平均） | 900万 |

会社規模による倍率は `1 + log10(スケール) × 0.32`（創業 ×1.00 → 世界最大 ×2.04）。

**給与水準**は5段階（×0.74〜×1.58）で、いつでも改定できる。

| 水準 | 士気 | 定着 | 採用力 |
|---|---|---|---|
| 業界最低水準 | −14 | −35% | −22% |
| 低め | −6 | −16% | −10% |
| 標準 | ± 0 | ± 0 | ± 0 |
| 高め | +7 | +18% | +10% |
| 業界最高水準 | +15 | +36% | +22% |

検証AI30試行での対照実験: 最低水準は幹部6.9名・士気66、最高水準は幹部11.1名・士気93。クリア月数は125 vs 122でほぼ変わらない。**速さを買うのではなく、会社の性格と粘り強さを買う選択**になっている。

#### 採用3ルート

| ルート | 時期 | 中身 |
|---|---|---|
| 新卒採用 | 年1回（決算ウィザード） | 方針と人数を決める。幹部候補として立つのは**4年後** |
| キャリア採用 | 随時 | 3名の候補から1名を選ぶ即戦力。給与水準が高いほど候補の質が上がる |
| ヘッドハント | 随時 | 他商社のエース。高額かつ失敗もある（信用・士気・給与水準に応じた成功率） |

**新卒採用の方針**（4種）で、同じ予算でも採れる人材が変わる。

| 方針 | 人数 | 単価 | 能力 | 幹部化率 |
|---|---|---|---|---|
| 量重視 | ×2.1 | ×0.70 | ×0.86 | ×0.42 |
| バランス | ×1.0 | ×1.0 | ×1.0 | ×1.0 |
| 質重視 | ×0.5 | ×2.1 | ×1.22 | ×3.4 |
| グローバル採用 | ×0.8 | ×1.5 | ×1.12 | ×1.7（海外拠点に配属され地域特性を持ちやすい） |

内定承諾率は給与水準・士気・信用で決まる（42%〜100%）。計画人数どおりには入社しない。

新卒を採らないと4年後以降の補充が止まり、離職と定年（63歳）で陣容が枯れる。
検証AIでの対照実験: 採用あり124ヶ月 / 採用なし146ヶ月でクリア。

### M&A（専門商社ステージ以降）

商談タブに買収候補が並ぶ。事業投資が「買って配当をもらう」だけなのに対し、M&A は買って・育てて・売る。

1. **デューデリジェンス** — 費用を払うと実力純利益と簿外債務が見える。目利きの高い幹部がいると最大50%安い。**省くと簿外債務をそのまま掴む**
2. **価格交渉** — 純資産倍率を5段階（×0.80〜×1.70）から選ぶ。高く出せば取れるが、のれんが重くなる
3. **のれん** — 買収価額 − 純資産。IFRS準拠で非償却。平時は無害だが統合失敗で一括減損する
4. **PMI（統合）** — 12ヶ月。統率の高い幹部を統合責任者に指名すると成功率が上がる（「PMIの鬼」は +25%）。のれんが厚いほど成功率は下がる
5. **EXIT** — 統合後は売却できる。シナジーと保有年数で売却額が伸びる

統合に成功した事業会社は、所属本部の採算（最大 +30%）と落札力（最大 +12pt）を押し上げる。

### 敵対的買収（負け方その2）

PBR が 0.72 倍を下回り、かつ株主信任が 48 を切ると、外資ファンドや同業から公開買付を仕掛けられる。防衛策は3つ。

| 防衛策 | 内容 |
|---|---|
| 自社株買い | 時価総額の22%を投じて株価を押し上げる。信任が高いほど成功率が上がる |
| ホワイトナイト | 株式24%を渡す代わりに資金と支援を得る。成功率86%だが独立性を失う |
| 株主に説明 | 無償。株主信任がそのまま成功率になる |

**防衛に失敗すると会社は消滅する。** 資金繰り破綻と並ぶ2つ目の負け方。

### 組織（中堅商社ステージ以降）

| 形態 | 効果 | 代償 |
|---|---|---|
| 単一組織 | 商談枠 +1 | 同時進行できる案件 −30% |
| 本部制 | 標準 | — |
| カンパニー制 | 各本部が自律的に稼ぐ（陣容に応じた営業外収益が毎月入る） | 配分可能額 −22%、ガバナンス低下 |
| グループ経営 | 間接費 −18%、買収企業のシナジー +30% | 商談枠 −1、ガバナンス低下 |

移行には純資産の3.5%と士気の低下を伴い、3年は戻せない。

### ガバナンスと社長信任（負け方その3）

**ガバナンス**が低いほど不祥事が起きる（制裁金・信用 −9・株主信任 −9・士気 −6）。サステナ・内部統制への予算配分で回復し、カンパニー制／グループ経営・高レバレッジ・幹部不足で低下する。

**6事業年度ごとに社長信任投票**がある。信任スコアは株主信任・直近2期の中計達成・ROE・ガバナンス・不祥事件数・世界順位から決まり、**40を切ると解任＝ゲームオーバー**。本社タブに現在のスコアと次の投票年度が常時出ているので、不意打ちにはならない。

純資産の30%を超える案件は**役員会**にかかり、幹部3名が賛否を述べる。反対多数でも押し切れるが、その責任は経営者が負う。

### 3つの負け方（検証AIでの発生率）

| 負け方 | 慎重な経営 | 凡庸な経営（万年無配・統治放置・大風呂敷の中計） | 無謀な経営（常時強気・限度いっぱいの借入） |
|---|---|---|---|
| 資金繰り破綻 | 0% | 3% | 100% |
| 社長解任 | 0% | 97% | — |
| 敵対的買収 | 0% | 発生する | — |

検証AIでのカード組み合わせ別クリア月数: 非資源+DX 138 / アジア+人材 129 / 財務規律+脱炭素 139 / 資源+提携 154。

勝ち筋は、トレードで稼いだフローを **権益・事業投資というストック収益** に変えていくこと。
無謀にレバレッジを効かせると格付が落ち、借入枠が縮み、資金繰りで死ぬ。

## 案件の4類型

| 種別 | 性格 |
|---|---|
| トレード | 運転資金を拠出し口銭を抜く短期取引。市況と為替で採算が振れる |
| プロジェクト | EPC/インフラ。毎月工事原価が出て竣工時に一括回収。遅延で原価が膨らむ |
| 資源権益 | 巨額の初期投資と引き換えに長期配当。市況低迷が続くと減損 |
| 事業投資 | 事業会社への出資。安定配当が毎月入り、投資先が自律的に成長する |

## 年次の業績

会計は **収益 − 費用 ＝ 当期純利益** が毎期ぴったり一致するように組んである（検証ツールが毎年チェックする）。

| 指標 | 中身 |
|---|---|
| 取扱高 | トレードの取扱総額・請負金額・傘下事業会社の年商の合計。商社らしい兆円単位の規模指標 |
| 収益（売上高） | 口銭・請負・配当・評価益の合計 |
| 費用 | 工事原価・人件費・販管費・支払利息・減損・貸倒 |
| 当期純利益 | 収益 − 費用 |
| 売上高純利益率 | 純利益 ÷ 収益 |

決算ウィザードの「決算発表」では年次業績・セグメント別損益・本部別の収益と取扱高が並ぶ。ダッシュボードには当期の累計、順位タブには**収益と純利益の年次推移グラフ**が出る（純利益は上向きが黒字、下向きの斜線が赤字。色だけに意味を持たせていない）。

## シミュレーション要素

- 商品市況6種（原油・LNG・鉄鉱石・銅・穀物・海上運賃）の対数平均回帰ランダムウォーク
- USD/JPY と政策金利の変動
- 地政学・気象・規制・信用不安など20種のイベント
- 信用力・ROE・D/E・サステナ投資 → 格付（AAA〜CCC）→ 借入枠・調達金利・落札力に波及
- 株価・時価総額・PBR・ROE・株主信任。PBR 1倍割れは資本効率の警告
- 昇格時、PBR が1倍を超えていれば公募増資で資金を調達できる
- D/E が 1.0 を超えると格付が毀損する財務規律
- 与信デフォルト、工程遅延、減損損失、資金繰り破綻（4ヶ月連続の債務超過でゲームオーバー）
- ライバル商社10社との世界ランキング

## 構成

```
index.html          エントリ
css/style.css       スタイル（ダーク／モバイルファースト）
js/data.js          静的データ（本部・案件テンプレ・イベント・ステージ）
js/engine.js        ゲームエンジン（会計・市況・入札・ターン処理・セーブ）
js/ui.js            描画レイヤー
js/main.js          入力配線
tools/              検証・ビルド用（ゲーム本体からは参照しない）
```

会計は **純資産 ＝ 現金 ＋ 簿価資産 － 有利子負債** で一貫しており、
損益計算書の各項目は必ず現金または簿価の増減と対になっている
（本部投資・採用・拠点開設・株主還元は資本取引として損益から分離）。

進行状況は `localStorage` に自動保存される。

## 開発用コマンド

```bash
node tools/sim.js 300 24     # 慎重な経営者AIでのバランス検証（昇格までの月数など）
SPREAD=1 node tools/sim.js    # 分散投資での対照実験
CARDS=resource node tools/sim.js  # 戦略カード別の検証（balanced/resource/asia/safe）
TIER=2 node tools/sim.js      # 中計の目標難易度別の検証（0/1/2）
NOHIRE=1 node tools/sim.js    # 人材を採用しない場合の対照実験
NOMA=1 node tools/sim.js      # M&Aをしない場合の対照実験
node tools/mediocre.js 30 180 # 凡庸な経営（無配・統治放置）での敗因分布
NOBUDGET=1 node tools/sim.js  # 予算配分なしでの対照実験
node tools/reckless.js 40    # 無謀な経営での破綻率
node tools/diag.js 30        # 月次の損益内訳トレース
node tools/build.js          # dist/index.html に単一ファイルとして出力
node tools/playtest.js       # 実ブラウザでのスモークテスト（要 playwright）
```
