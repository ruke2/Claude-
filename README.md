# 摩天楼の設計図 — URBAN DEVELOPER SIMULATOR

架空都市「湊都（みなと）市」を舞台にした、不動産デベロッパーの経営シミュレーションゲーム。
用地の仕入れから複合施設のフロア構成、ブランドづくり、販売・賃貸運用、資金調達、人事、M&A までを一貫して扱う。

ビルド不要。`index.html` をブラウザで開けば動く（ES Modules / Canvas 2D、外部ライブラリなし）。

```bash
# ローカルで動かす（ES Modules のため file:// ではなく HTTP で開くこと）
python3 -m http.server 8000
# → http://localhost:8000/index.html
```

---

## ゲームの目的

自己資本 200 億円の新興デベロッパーとして創業し、四井不動産・三陵地所といった業界の巨人がひしめく
湊都市で事業を拡大する。**1ターンは1週間**。四半期（13週）ごとに決算を締め、売上・利益・純資産を
積み上げて業界ランキングの上位を目指す。

登場する競合 8 社はすべて架空の企業である。

- **季節で時間帯が変わる** — 冬は夜景、春は早朝、夏は正午、秋は夕景

## 事業のサイクル

### 1. 用地取得
週ごとに売却情報が持ち込まれる。件数は用地開発部の陣容で決まる。

- **一般競争入札** — 最高価格で落札
- **事業提案コンペ** — 価格に加えて企画内容が評価される。ブランドで劣る序盤でも勝てる
- **相対（先着）** — 売主の提示額で即時取得。ただし割高で瑕疵が隠れていることも多い

土地には **土壌汚染・埋蔵文化財・地中障害物・近隣反対運動・借地権の未整理・日影規制** などが
潜んでいる。デューデリジェンスに費用をかけると事前に判明し、被害を抑えられる。
好材料（容積率割増の見込み、新駅設置計画）が見つかることもある。

各案件では **残余法**（完成後の価値から建設費と目標利益を差し引いた、土地に払える上限）が
表示される。これを超えて入札すると高値掴みになる。

> 大手は自社の売上規模に見合わない小型案件には入札してこない。序盤はここが勝負どころになる。

### 2. 企画 — フロア構成を組む
用途（8種）とグレード（スタンダード／ハイグレード／ラグジュアリー）を決める。
**複合再開発**を選ぶと、フロアスタックを自分で組み立てられる。

```
  17〜24階  賃貸レジデンス  8F   NOI 21.8億円／年   ×1.09
  15〜16階  分譲マンション  2F   分譲 145億円       ×1.03
   4〜14階  オフィス       11F   NOI 48.2億円／年   ×1.01
   1〜 3階  商業施設        3F   NOI 11.4億円／年   ×1.00
```

用途ごとに**適正な階層帯**がある。商業は低層でこそ力を発揮し、7階以上に置くと収益が半減する。
住宅は上層ほど高く売れ、ホテルは低層階では単価が落ちる。配置を誤ると補正が 1.00 を下回り、
同じ床面積でも稼げなくなる。容積率の消化状況はリアルタイムに表示され、超過した計画は着工できない。

### 3. 建設
工事代金は出来高に応じて毎週支払う。資材高騰による増額、労災、長雨、VE提案によるコスト圧縮といった
イベントが発生する。オフィスビルで約2年、複合再開発で約3年かかる。

### 4. 販売・運用
- **分譲** — 工事進捗 25% から青田売りが可能。価格を市場相場からどれだけ動かすかで契約速度が変わる。
  長期在庫は評価損を生む
- **賃貸** — 竣工直後の稼働率は低く、リーシング力で徐々に埋まる。2年ごとに賃料改定。
  保有し続けるか、キャップレートで売却して資金を回収するかを選ぶ

## ブランド

用途カテゴリごとに**自社ブランドを立ち上げて育てられる**。分譲マンション、戸建、賃貸レジデンス、
オフィス、商業施設、ホテル、物流施設の7カテゴリ。

- 格は3段階（ボリューム／アッパー／プレミアム）。格が高いほど立ち上げ費用は重く、育成に時間がかかるが、
  最終的な単価補正と認知度の上限が大きい
- 物件にブランドを冠すると、**分譲単価・契約速度・賃料**が認知度に応じて上乗せされる
- 供給を重ねるたびに認知度が上がり、早期完売は評判を押し上げる
- 値下げ・長期在庫・減損は評判を傷つける。供給が途絶えると少しずつ忘れられていく
- 広告投資で認知度を維持・向上できるが、供給実績を伴わない認知はすぐ頭打ちになる

## 財務

四半期ごとに損益計算書と貸借対照表が確定する。費用は毎週発生し、四半期末に締める。

- 売上高／売上原価／販管費（人件費を含む）／営業利益／支払利息／経常利益／特別損益／当期純利益
- 現金・販売用不動産・仕掛用地・建設仮勘定・賃貸等不動産・のれん／有利子負債／純資産
- 建設中の案件に対応する借入金利は建設仮勘定に算入される
- 保有不動産の含み益（簿価には表れないが企業価値に反映される）
- 信用格付（AAA〜B）が調達金利を決める。借入枠は「純資産 × レバレッジ ＋ 不動産の担保価値」
- 借入枠を超えると当座借越となりペナルティ金利がかかる。4四半期続くと支払不能で終了
- 条件を満たせば **株式上場**。以降は株価・時価総額・EPS が算出され、公募増資もできる

## 人事制度

- **8 部署**（用地開発・商品企画・建設管理・販売事業・ビル事業・財務経理・人事総務・経営企画）と
  **8 等級**（社員〜代表取締役社長）。課長以上は枠が限られる
- 社員は **6 つの能力**（用地・企画・施工・営業・財務・統率）、潜在能力、年収、モチベーション、
  定着度を個別に持つ
- **組織図** で課長以上を個人表示。クリックすると異動・昇格・昇給・退職勧奨ができる
- **給与テーブル係数** を改定すると全社員の年収水準が動く。市場水準を下回るとモチベーションが落ち、
  競合に引き抜かれる
- **社内研修／福利厚生／業務DX／採用ブランディング** への投資

### 新卒採用（年次サイクル）

| 時期 | 内容 |
| --- | --- |
| 3月第1週 | 会社説明会・エントリー受付開始。採用活動費を一括計上し、母集団が形成される |
| 3〜6月 | インターンとリクルーターへの投資が学生の志望度を押し上げる |
| 6月第1週 | 書類選考。計画の6倍までが面接に進む |
| 6〜7月 | 面接を重ねるほど、学生の実力の推定幅が狭まる |
| 7月第1週 | 内定出し。放置すると他社に決まってしまう |
| 7〜10月 | 内定者へのフォロー面談で承諾率を上げられる |
| 10月第1週 | 内定式。志望度の低い学生は辞退する |
| 翌4月第1週 | 入社 |

学生には出身校ランク（最難関大〜一般大）があり、能力と潜在能力の期待値が変わる。
**実力は最初から見えない。**人事総務部の能力とインターン投資によって推定の精度が上がり、
選考が進むほど誤差が縮む。採用活動への投資は説明会・インターン・広告・リクルーターの4項目に配分する。

### 中途採用

| チャネル | 特徴 |
| --- | --- |
| 人材エージェント | 年収の30%の成功報酬。質の高い即戦力が集まる |
| 自社サイト公募 | ほぼ無償だが質がばらつく。企業ブランドが低いと人が集まらない |
| リファラル（社員紹介） | 定着率が高く安価。社員の士気が高くないと紹介が出てこない |
| ヘッドハンティング | 極めて高コスト・低定着率。一人で事業が変わることもある |

部署の「質」（加重平均能力）と「量」（処理能力）が、入札の勝率、工期、原価、契約速度、
稼働率、調達金利、M&A の成否に直結する。

## 子会社と M&A

### 子会社の設立
建設・販売・不動産管理・REIT運用・海外事業の 5 種類。
出資金と年間固定費がかかり、本体から人員を出向させる。

効果の例：建設子会社は建設原価 −6%・工期 −10%、販売子会社は契約速度 +15%、
REIT 運用会社は物件売却額に +8% のプレミアム。

一方で、**仕事量が足りなければ固定費だけが残る**。海外事業子会社は損益が大きく振れる。

### 買収
中小企業の売却案件が持ち込まれる。売上・営業利益・純資産・従業員数と提示価格が開示される。

買収先には **簿外債務・不適切な会計処理・キーマン依存・企業文化の不一致・係属中の訴訟・
顧客の極端な集中・基幹システムの老朽化** が潜む。デューデリジェンスで事前に把握していれば
被害は半分以下に抑えられる。

買収後は PMI（統合）が進み、完了するとシナジーが完全に発現する。
逆に業績が計画を下回れば **のれんの減損** となり、最悪の場合は買収そのものが失敗に終わる。
のれんは 20 年で均等償却される。

## 市況

景気は約 10 年周期で循環する（回復 → 好況 → 過熱 → 後退 → 不況）。
不動産価格指数・建設費指数・長期金利・用途別需要指数が連動して動く。

さらに、金融危機、インバウンド需要の爆発、建設資材の高騰、規制緩和、大規模地震、
リモートワークの定着、REIT 市場への資金流入といったショックが不定期に発生する。
